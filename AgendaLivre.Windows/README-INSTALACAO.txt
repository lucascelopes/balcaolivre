AGENDA LIVRE PARA WINDOWS

1. Extraia todo o conteudo do arquivo ZIP para uma pasta.
2. Abra AgendaLivreWindows.exe.
3. Crie sua conta ou entre com a mesma conta usada na versao Web.

O pacote ja inclui o runtime necessario e nao exige a instalacao do .NET.

Se o Windows SmartScreen exibir um aviso por o aplicativo ainda nao ter
assinatura digital, confira o nome "Agenda Livre" antes de escolher
"Mais informacoes" e "Executar assim mesmo".
